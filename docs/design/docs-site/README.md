# Docs site, design reference

The agreed design for the in-portal documentation site (`/docs`): the reference layout with a compact
"Start here" checklist in the right rail (variant 4 of the three explored).

- `docs-v4-reference-with-checklist.html`: clickable mockup. Open it in a browser (it reads the Geist fonts
  from `node_modules`, so run `npm install` first; the icons load from the Phosphor web CDN). The dashed
  "Preview as" bar at the top is a mockup control only: it shows how the guides and the checklist filter by role.
- `img/`: screenshots of the same mockup (home as a leadership billet, trooper and Admin; an article; the
  checklist with progress; dark theme).

The guide copy in the mockup is placeholder text. Screenshot panels are placeholders for real captures.
